# About Alex Gekas

I'm Alex Gekas, a technical writer focused on API and developer documentation. I write for developers who need to understand an API, integrate it with another system, or build on top of it.

I'm available for freelance and contract technical-writing projects.

## What I write

- **API reference documentation:** endpoints, parameters, request and response examples, status codes, and authentication.
- **Developer tutorials:** step-by-step guides that end in a working, testable result.
- **Integration guides:** connecting one system to another, such as a REST API to Slack.
- **SaaS documentation:** setup, getting-started, and troubleshooting content for software products.
- **Technical explainers:** concept guides that give readers just enough background to use a technology.

## How I work

- I write in Markdown and manage docs in Git, following a docs-as-code workflow.
- I publish with MkDocs and Material for MkDocs.
- I test API requests with Postman and curl before documenting them.
- I lint with Vale and follow the Google developer documentation style guide.
- I structure content with the Diátaxis framework, keeping concepts, tutorials, how-to guides, and reference separate.
